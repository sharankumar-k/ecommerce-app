# 🛒 E-Commerce Web Application

A full-stack E-Commerce Web Application built using **Spring Boot**, **Spring Security**, **JWT Authentication**, **PostgreSQL**, and **React.js**.

The application provides secure user authentication, product management, shopping cart functionality, wishlist management, order processing, payment handling, and role-based access control.

---

## 👤 User Features

- User Registration
- User Login
- JWT Authentication
- Browse Products
- View Categories
- Add Products to Cart
- View Cart
- Add Products to Wishlist
- Place Orders
- Make Payments

## 👨‍💼 Admin Features

- Admin Login using JWT Authentication
- Access to Admin Dashboard
- Category Management (Create, View, Update, Delete)
- Product Management (Create, View, Update, Delete)
- Role-Based Access Control
- Protected Admin Routes

## ▶️ Running the Application

### Backend

```bash
cd ecommerce-backend
mvn spring-boot:run
```

### Frontend

```bash
cd frontend
npm install
npm start
```

Application URLs:

```text
Backend : http://localhost:8080
Frontend: http://localhost:3000
```
